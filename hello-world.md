### What is Monetize?

Monetize is an app that allows users to:
- Track their spending and income
- Set their own budgets 
- Create savings goals
- Manage their financial health

## Getting Started

To get started with this project:

1. **Clone the repository**
2. **Install dependencies** in the frontend directory
3. **Run the development server**

```bash
cd frontend
npm install
npm run dev
```
